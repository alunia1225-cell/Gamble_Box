GAMBLE BOX 3.0
フル演出版・仮想カジノWebアプリ

主な更新:
- 全ゲームにWeb Audio APIベースのSEを追加
- プチュン演出: 暗転 + 特殊音 + 一時無音
- ブラックジャック: HIT / STAND / DOUBLE / SPLITボタン
- ブラックジャックのカードデッキ・Aの11/1判定・ディーラー17ルール
- テキサスホールデムへ変更
- ホールカード2枚 / コミュニティカード5枚
- CHECK / CALL / BET / RAISE / FOLD / ALL-IN相当の自由ベット入力
- CPU 1人対戦
- 役判定: Straight Flush / Four of a Kind / Full House / Flush / Straight / Three of a Kind / Two Pair / Pair / High Card
- 既存のスロット / ダイス / ルーレット / 丁半 / コイン / 宝くじ / Crash / Daily / Shop
- localStorageで仮想コインと履歴を保存
- スマホ対応

音について:
外部音源ファイルは不要です。ブラウザのWeb Audio APIでSEを生成します。
ブラウザの仕様上、最初の画面タップ後に音声コンテキストが有効になります。

起動:
index.html をブラウザで開いてください。

実際のお金は扱わず、仮想コインのみです。
